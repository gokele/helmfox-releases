# HelmFox

一个跑在自己电脑上的数据库管理工具。支持 **PostgreSQL、MySQL 与 MariaDB**。

连接配置、查询历史、备份文件全部留在本机,不经过任何服务器。除了检查更新,
软件不联网 —— 断网时除了连远程库,其余功能照常可用。

[**下载最新版本**](https://github.com/gokele/helmfox-releases/releases/latest) ·
macOS 与 Windows · 免安装 · 简体中文

---

## 它把哪几件事做顺了

浏览和修改数据库,大部分时间花在很具体的几个动作上:找到那张表、看看里面有
什么、改几行、写一段查询、把结果导出来。HelmFox 把这几件事做顺,并且在容易
出事的地方拦一道。

**像用表格一样改数据。** 双击单元格就能改,方向键移动、Shift 扩选、
Cmd/Ctrl+A 全选、Cmd/Ctrl+C 直接复制,和电子表格一个手感。改动是攒着的,
按「保存」之前随时可以丢弃。

**保存前给你看的是语句,不是数量。** 不写"将修改 3 行",而是把即将执行的
`UPDATE` 原样摆出来,参数都填回了真实的值 —— 核对的价值全在值上。

**改错了能整体撤回。** 打开编辑器上的「事务」开关,这个标签就独占一条连接,
删多了、改错了,按「回滚」就当没发生过。事务开着的时候屏幕上一直挂着提示,
写着这些改动**还没有落地** ——「我到底提交了没有」是这条路上最容易记错的事。

**危险的语句先问一句。** `DROP`、`TRUNCATE`、不带 `WHERE` 的 `DELETE` 与
`UPDATE` 会弹出确认,并把语句原文摆给你看。而带了 `WHERE` 的、普通查询、
字符串和注释里出现这些词的一律不问 —— 天天弹的确认框等于没有确认框。

**报错说人话。** 连不上会告诉你是密码不对、库不存在、端口上那个服务不像
PostgreSQL,还是防火墙挡住了,并给出下一步怎么办。保存数据出错会直接说是
哪一列、什么问题(不能留空 / 值重复 / 类型对不上 / 被外键指着)。
原始报错也保留着,不掩盖信息。

## 能做些什么

**浏览与编辑** —— 对象树按需加载,连接按数据库种类分组并挂上各自的品牌标记。
表结构、索引、外键、约束、触发器一应俱全,DDL 随时可看。跨 schema 按名字搜
对象:你记得住表名,未必记得住它在哪个 schema。

**写 SQL** —— 语法高亮、按库结构自动补全、Cmd/Ctrl+Enter 执行、可执行选中
片段、可中断正在跑的查询,报错直接定位到出错位置。带执行历史与收藏。

**执行计划不只画出来,还给结论** —— 除了计划树,会直接指出白扫的行、过期的
统计信息、落盘的排序、内层没索引的嵌套循环,并给出可以直接执行的那一句。
每条结论都带着它依据的数字;建议只贴进编辑器,绝不代你执行。

**字段血缘** —— 一个视图或一段查询,每个输出列到底由哪些表的哪些列算出来。
嵌套视图、UNION、聚合与窗口函数都能穿透,对不准的边会明确标成「可能」。

**导入导出** —— CSV、Excel、JSON、Parquet 拖进窗口就能预览;确认无误再建表
导入,列类型自动推断。导出支持 CSV / JSON / Excel / SQL,按行流式写出,
不限行数。

**运维** —— 备份与恢复、结构快照与比对(并生成可直接执行的迁移语句)、两个库
之间的表数据比对、跨库搬运数据(两端可以是不同种类的库)、ER 图、性能面板、
用户与权限管理。

> 三种数据库的支持深度不完全一样,这是有意的。做不了的功能在界面上**根本
> 没有入口**,而不是让你填完表单、按下执行才发现这条路不通。

## 下载与安装

到 [Releases](https://github.com/gokele/helmfox-releases/releases/latest) 页取最新版本。

| 平台 | 下载文件 | 说明 |
|---|---|---|
| macOS 11+ | `HelmFox-<版本>.dmg` | Apple 芯片与 Intel 通用 |
| Windows 10 1809+ | `HelmFox-<版本>-windows-amd64.exe` | 免安装单文件 |
| Windows on ARM | `HelmFox-<版本>-windows-arm64.exe` | 免安装单文件 |

页面上还有几个 `.zip` 与一份 `updates.json`,那是软件自动更新时用的,
手动下载请忽略。

**macOS** —— 双击 dmg 挂载,把 HelmFox 拖进「应用程序」,弹出即可。
安装包已签名并通过 Apple 公证,不会出现「无法验证开发者」的拦截。

**Windows** —— 下载 exe 直接双击运行,不需要安装。首次运行会被 SmartScreen
拦一次,点「更多信息 → 仍要运行」。

需要 WebView2 运行时:Win11 与打过更新的 Win10 自带,缺少时装一个
[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

**把 exe 放在有写权限的目录**,用户目录下任意位置都行。自动更新是就地替换
这个 exe,放进 `C:\Program Files` 会因为需要管理员权限而更新失败。数据不跟
exe 放在一起,换掉 exe 不影响任何配置。

## 第一次使用

打开软件 → 点「连接到数据库」→ 填主机、端口、数据库名、用户名和密码 →
在左边的树里展开,双击一张表就能看到数据。

不知道主机和端口该填什么?首屏还有一个「扫描本机项目」,它能从你机器上的
项目配置里把可用的连接找出来,不用自己去翻。

## 你的数据放在哪

| 系统 | 位置 |
|---|---|
| macOS | `~/.helmfox` |
| Windows | `%USERPROFILE%\.helmfox` |

里面是元数据库 `helmfox.db` 与备份目录 `backups/`。

**连接密码存在系统钥匙串里,从不写进这个数据库。** 数据库里的连接信息、
SQL 历史与结构快照经 AES-GCM 加密存储,主密钥同样在钥匙串里 —— 单独拿到
`helmfox.db` 这个文件是解不开的。

需要把连接带到另一台机器时,可以导出成一份口令加密的文件;也支持从
DBeaver 与 Navicat 导入。

卸载时删掉程序本体即可。数据目录里还放着你的备份文件,需要的话先取走。

## 自动更新

启动后、以及你回到软件跟前时静默检查一次,**只有确实存在新版本时才弹窗**,
由你决定立即更新、跳过此版本还是稍后提醒。没联网就跳过,不打扰也不报错。
也可以随时从菜单或托盘手动检查。

更新包由 Ed25519 私钥签名,公钥编译期钉死在程序里,下载后逐字节校验摘要与
签名 —— 即使这个仓库被拿下,没有私钥也发不出一个能装上的更新。

## 系统要求

- macOS 11 或更高
- Windows 10 1809 或更高,需要 WebView2 运行时
- 目标数据库:PostgreSQL 12+ / MySQL 8.0+ / MariaDB 10.4+
- 备份与恢复需要本机装有对应的命令行工具(`pg_dump` / `mysqldump` /
  `mariadb-dump`),版本不低于目标服务端
